# Sistema de Gestión para Casa Reparadora de Computadoras (U-Tech)

Sistema web completo desarrollado para gestionar el flujo de trabajo de una casa matriz de reparación de computadoras y sus sucursales.

##  Demostración en Video
https://youtu.be/BckUcUAaqVI

##  Tecnologías Utilizadas
*   **Backend:** C#, ASP.NET Core MVC (.NET 9)
*   **Base de Datos:** SQL Server (ADO.NET)
*   **Frontend:** HTML5, CSS3, Bootstrap, jQuery
*   **Generación de Reportes:** iTextSharp (PDF)
*   **Seguridad:** Autenticación por sesiones y control de acceso basado en roles.

##  Características Principales
*   Gestión de múltiples sucursales.
*   Registro de clientes y sus equipos (computadoras).
*   Flujo completo de reparación: Recepción -> Diagnóstico -> Reparación -> Entrega.
*   Generación de expedientes y reportes en PDF.
*   Paneles de control diferenciados por roles (Administrador, Gerente, Recepcionista, Técnico).
